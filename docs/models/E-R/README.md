# Modelo(s) Entidad-Relacion

En este caso se mostrará un diagrama E-R unificado, el cual tendrá todas
las entidades del proyecto, pero algunas realmente no se guardarán en una
base de datos relacional (ReporteSeguridad, Sitio, Review, Servicio), asi
que para estas, se buscará la manera de representarlas aparte. Sin embargo,
están definidas en este modelo para entender las relaciones con otras
entidades.
